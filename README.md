## Recognition philosophy

**Learn → Apply → Validate → Grow → Own → Transform → Multiply → Sustain.** Recognition is based on verified outcomes, not purchased membership, passive attendance or certificates alone. All career stages and membership tiers have access. The levels are milestones, not substitutes for qualification or professional certification.

**Architecture relevance:** 12 Architecture Streams × 11 GICS sectors. **Learning arc:** Origin Story → Pre-Foundation → Foundation → Essentials → Advanced → Ultimate, distinct from awards. Seven learning domains: HR, CX, Finance, Procurement, SCM, BTM and Leadership & Identity Transformation.
